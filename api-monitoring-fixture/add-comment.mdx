`POST /v1/incidents/{incident_id}/comments`

Add a comment to an incident. Comments can be added after an incident is resolved, so the final follow-up stays with the incident record. Send an `Idempotency-Key` header when retrying this request.

## Path parameter

| Name | Type | Description |
| --- | --- | --- |
| `incident_id` | UUID | ID of the incident. |

## JSON request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `body` | string, 1–5000 characters | Yes | Comment text. |
| `author_id` | string | Yes | ID of the author. |
| `visibility` | `public`, `internal` | No | Defaults to `internal`. |

```json
{
  "body": "Investigating the checkout deployment from 11:45 UTC.",
  "author_id": "usr_17",
  "visibility": "internal"
}
```

## Response — HTTP 201

```json
{
  "id": "cmt_01J9K7PQ2B",
  "incident_id": "8a65861a-d78e-4330-8763-18e8cb67c190",
  "body": "Investigating the checkout deployment from 11:45 UTC.",
  "visibility": "internal",
  "author": { "id": "usr_17", "display_name": "Morgan" },
  "created_at": "2026-10-06T12:08:00Z"
}
```

`400 invalid_request` means a field is missing or invalid. `404 incident_not_found` means the incident does not exist.
